# archjbald.github.io

Personal portfolio of Romain Guesdon — Computer Vision & ML Engineer.

A single static `index.html` with inline CSS. No build step, no JavaScript, no
external dependencies. Open the file directly in a browser, or let GitHub Pages
serve it as-is.
